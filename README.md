## Run locally

The site uses React, TypeScript, Vite, Material UI, and Motion. It supports desktop and mobile layouts with light and dark themes.

From the directory containing `package.json`, use Node.js 22.12 or later and run the following commands.

```bash
npm ci
npm run dev
```

## Build for GitHub Pages

```bash
npm run build && cp LICENSE dist/
```

Run `npm run preview` to check the production build locally. For a manual deploy, upload the contents of `dist/` to the configured GitHub Pages publishing location.
